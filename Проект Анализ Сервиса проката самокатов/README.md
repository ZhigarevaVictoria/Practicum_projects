# Анализ сервиса проката самокатов GoFast


## 📊 Обзор проекта

Цель: Провести анализ пользователей сервиса проката самокатов, изучить их поведение (длительность и дистанцию поездок), проверить статистические гипотезы о различиях между пользователями с подпиской и без, а также оценить экономическую эффективность платной подписки.

Дата выполнения: 10.04.2026


## 📁 Данные

Используются три датасета:

1.`users_go.csv` — таблица с пользователями
   - `user_id` — уникальный идентификатор пользователя
   - `name` — имя пользователя
   - `age` — возраст
   - `city` — город
   - `subscription_type` — тип подписки (`free`, `ultra`)

2. `rides_go.csv` — таблица с поездками
   - `user_id` — идентификатор пользователя
   - `distance` — расстояние в метрах
   - `duration` — продолжительность сессии в минутах
   - `date` — дата поездки

3. `subscriptions_go.csv` — таблица с подписками
   - `subscription_type` — тип подписки
   - `minute_price` — стоимость минуты поездки
   - `start_ride_price` — стоимость начала поездки
   - `subscription_fee` — ежемесячный платёж


## 📈 Этапы анализа


### 1. Загрузка и предобработка данных
   - Импорт данных из CSV-файлов по ссылкам
   - Преобразование `date` в формат datetime
   - Создание столбца `month` с номером месяца
   - Поиск и обработка пропусков (31 дубликат удалён)
   - Округление `duration` до целого числа (плата только за полные минуты)

### 2. Исследовательский анализ данных (EDA)
   - Анализ количества пользователей по городам и типам подписки
   - Визуализация соотношения подписок (круговая диаграмма)
   - Гистограмма распределения возраста пользователей
   - Расчёт доли несовершеннолетних пользователей
   - Описательная статистика длительности поездок

### 3. Объединение данных
   - Слияние таблиц пользователей и поездок (`left` join по `user_id`)
   - Присоединение информации о тарифах (`left` join по `subscription_type`)
   - Создание отдельных датафреймов для пользователей с подпиской (`ultra`) и без (`free`)

### 4. Подсчёт выручки
   - Группировка данных по `user_id`, `name`, `subscription_type`, `month`
   - Агрегация: сумма дистанции, сумма длительности, количество поездок
   - Расчёт месячной выручки
   - Поиск пользователя с максимальной выручкой за весь период

### 5. Проверка статистических гипотез
   - Гипотеза 1: Средняя длительность поездки у пользователей с подпиской больше, чем у пользователей без подписки
   - Гипотеза 2:** Средняя дистанция поездки у пользователей с подпиской больше 3130 м
   - Гипотеза 3: Средняя месячная выручка от пользователей с подпиской выше, чем от пользователей без подписки

### 6. Моделирование распределений
   - Расчёт вероятности поездки более 30 минут (нормальное распределение)
   - Расчёт вероятности поездки в интервале 20–30 минут
   - Определение критической дистанции (90-й процентиль)

## 💡 Рекомендации для бизнеса

1. Развивать подписку `ultra` — пользователи с подпиской приносят значительно больше выручки (428 руб против 200 руб)

2. Стимулировать переход на подписку — подписчики совершают более длительные поездки (20 мин vs 18 мин), что увеличивает выручку

3. Внедрить дополнительную плату за сверхдлительные поездки — только 1.5% поездок превышают 30 минут, введение платы не затронет большинство пользователей

4. Установить порог для дополнительной платы на дистанции — 90% поездок укладываются в 3 521 метр
