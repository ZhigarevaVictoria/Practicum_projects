# Изучение развития игровой индустрии с 2000 по 2013 год


## 📊 Обзор проекта

**Цель:** Изучить развитие игровой индустрии с 2000 по 2013 год на основе данных о продажах игр, популярности платформ и жанров, а также пользовательских и экспертных оценках.

**Дата выполнения:** 28.01.2026


## 📁 Данные

Проект использует датасет `new_games.csv` (16 956 записей, 11 полей):

- `Name` — название игры
- `Platform` — название платформы
- `Year of Release` — год выпуска игры
- `Genre` — жанр игры
- `NA sales` — продажи в Северной Америке (млн копий)
- `EU sales` — продажи в Европе (млн копий)
- `JP sales` — продажи в Японии (млн копий)
- `Other sales` — продажи в других странах (млн копий)
- `Critic Score` — оценка критиков (от 0 до 100)
- `User Score` — оценка пользователей (от 0 до 10)
- `Rating` — рейтинг ESRB (возрастная категория)


## 📈 Этапы анализа

### 1. Загрузка и знакомство с данными
- Импорт данных из CSV-файла по ссылке
- Вывод первых строк и общей информации о датасете
- Анализ структуры данных и типов столбцов

### 2. Предобработка данных

**Приведение названий столбцов к snake_case:**
- `Year of Release` → `year_of_release`
- `NA sales` → `na_sales`
- `EU sales` → `eu_sales`
- `JP sales` → `jp_sales`
- `Other sales` → `other_sales`
- `Critic Score` → `critic_score`
- `User Score` → `user_score`

**Преобразование типов данных:**
- `year_of_release` → `datetime64`
- `eu_sales`, `jp_sales` → `float32`
- `critic_score`, `user_score` → `float32`
- `rating` → `category`

**Обработка пропусков:**
- Удалены строки с пропусками в `name` и `genre` (2 строки)
- Пропуски в `year_of_release` заполнены медианным значением для каждой комбинации платформы и жанра
- Удалены строки, где `year_of_release` остался NaN (275 строк)
- Пропуски в `critic_score`, `user_score`, `rating` оставлены (допустимы, 40-50% данных)

**Удаление дубликатов:**
- Очистка названий игр от региональных пометок и символов (регулярные выражения)
- Удаление 238 явных дубликатов
- **Итого удалено:** 242 строки (1.43% от исходных данных)

### 3. Фильтрация данных
- Отбор игр за период с 2000 по 2013 год включительно
- Сохранение отфильтрованных данных в датафрейм `df_actual` (13 022 записи)

### 4. Категоризация данных

**Категории пользовательских оценок (`user_score`):**
- Высокая оценка: от 8 до 10
- Средняя оценка: от 3 до 8 (не включая 8)
- Низкая оценка: от 0 до 3 (не включая 3)
- Нет оценки: отсутствует

**Категории экспертных оценок (`critic_score`):**
- Высокая оценка: от 80 до 100
- Средняя оценка: от 30 до 80 (не включая 80)
- Низкая оценка: от 0 до 30 (не включая 30)
- Нет оценки: отсутствует
